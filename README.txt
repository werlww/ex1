ПРОТОТИП КОФЕЙНИ «ТЁПЛЫЙ УГОЛ»

1. Создай проект Next.js с TypeScript, App Router и Tailwind CSS.
2. Распакуй архив.
3. Скопируй папки app, components, lib и public в корень проекта, согласившись на замену app/globals.css и app/layout.tsx.
4. В терминале выполни: npm run dev
5. Открой http://localhost:3000

Страницы: /, /menu, /about, /contacts и /menu/[id].
Адрес, телефон и почта демонстрационные — при необходимости замени их.
